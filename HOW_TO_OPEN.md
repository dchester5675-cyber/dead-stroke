# The wheel will not run inside the Grok chat preview

That preview is a download card. It does not execute JavaScript, so the wheel looks dead.

## Android — do this

1. Download `DEAD_STROKE_WHEEL.html` from the Grok chat.
2. Open **Chrome** (not Grok, not Drive, not a text editor).
3. Open the **Files** app → Downloads → tap the file.
4. If it asks how to open it, pick **Chrome**.
5. If you only see code, you opened a text viewer. Tap the three dots → Open with → Chrome.
6. Tap **SPIN** or tap the wheel itself.
7. Chrome menu → **Add to Home screen**.

## Make the live link

1. Open https://github.com/dchester5675-cyber/dead-stroke
2. Add file → Upload files → upload the HTML → name it `index.html` → Commit.
3. Settings → Pages → Deploy from branch → main / root → Save.
4. Wait one minute, then open:
   https://dchester5675-cyber.github.io/dead-stroke/
