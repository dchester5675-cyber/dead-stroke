# DEAD STROKE

Two-player adult confession spin wheel. 18+.

## Play on your phone tonight

Download `index.html` from this repo (or the file from the Grok chat). Open it in Safari or Chrome. Share → Add to Home Screen. It launches full-screen like an app and works offline after the first load.

## Make it a real link

Repo → Settings → Pages → Deploy from branch → `main` / root → Save.

Live URL after a minute:

https://dchester5675-cyber.github.io/dead-stroke/

## Rules in one breath

P1 spins. P2 answers out loud. One follow-up on the same wound. Then swap.

- Rack: solids = body, stripes = bone, 8 = the knife. Used slices fall off.
- Foul / Scratch: hedging, a real scratch, or a Smoke.
- Winner’s Claim: after the 8, or when the rack is empty. Say it. Collect it.
